# Dave's Fry Catch

A fast, arcade-style browser game where you catch seasoned fries, build a
combo, grab sauce power-ups, and dodge Reaper peppers for as long as your three
lives hold out.

## Capital One Tech Summit

Building this game was part of the Capital One Tech Summit. I took some
creative liberty with the summit's "falling coin catch" design spec and
reimagined it as a high-energy arcade game where you catch the best french
fries: Dave's Hot Chicken fries.

## Play

Open `index.html` directly in a browser, or run:

```bash
npm install
npm run dev
```

Then visit `http://localhost:3000`.

## Controls

- Move with <kbd>A</kbd>/<kbd>D</kbd> or the left/right arrow keys.
- Catch regular and golden fries to raise your score.
- Catch sauce to activate the fry magnet.
- Avoid Reaper peppers.
- Press <kbd>M</kbd> to toggle sound.

Scores are unlimited, difficulty ramps to its maximum pace, and the local high
score is saved in the browser.
